# Ukázkový repozitář kurzu B1

Vítejte! Pokud tohle čtete ve svém terminálu nebo ve VS Code, právě jste úspěšně použili `git clone`. 🎉

Tento repozitář je součástí kurzu **Příprava prostředí pro práci s AI agenty** (PEF ČZU, aktivita PPSŘ).

## Co se právě stalo

Příkazem `git clone` jste si z GitHubu stáhli celý projekt, a to **včetně jeho historie**. Nejsou to jen soubory, jako kdybyste stáhli ZIP. Máte u sebe i všechny uložené verze, jejich popisky a autory.

## Otázka pro vás

Zjistěte příkazem `git log --oneline`:

1. Kolik verzí (commitů) tento repozitář má?
2. Jak se jmenuje nejnovější verze?

Celé podrobnosti, včetně autorů a data, ukáže `git log` bez `--oneline`. Pokud je výpis dlouhý a dole je dvojtečka, ukončíte ho klávesou `q`.

Ne, k tomuto repozitáři nemáte práva k zápisu, a to je dobře. Kopii ve svém počítači ale můžete upravovat, jak chcete, a ukládat do ní vlastní verze. Na GitHub nahráváte do svého repozitáře `podklady-predmet`.
